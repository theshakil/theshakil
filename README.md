# 👋 Hi, I'm Shakil

I'm building my career toward becoming a **Senior AI Android Engineer** — combining Android engineering, artificial intelligence, machine learning, backend engineering, and modern web technologies.

- 🤖 **AI & Machine Learning:** Training and deploying models with PyTorch, TensorFlow, NumPy, and Pandas.
- ⚛️ **Web Development:** Building responsive full-stack apps with Next.js, TypeScript, and Tailwind CSS.
- ⚙️ **Backend Engineering:** Developing REST APIs and services with Java, Spring Boot, Python, and PostgreSQL.
- ☁️ **AI Systems Thinking:** Designing hybrid on-device/cloud AI architectures for real production use cases.
